# Folio Client

Next.js App Router + React + TypeScript CV workspace. The API URL defaults to `http://localhost:8000/api/v1` and can be changed with `NEXT_PUBLIC_API_URL`. Set `NEXT_PUBLIC_ADMIN_URL` to the deployed admin app URL.

Run `npm install` and `npm run dev`. The editor uses dnd-kit for pointer and keyboard-driven reordering. `@react-pdf/renderer` powers both the inline PDF viewer and the PDF download from the same document component.
